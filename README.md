## 🔊 DeafSupport  
A cross‑platform spatial sound radar designed for Deaf and Hard‑of‑Hearing users.

**Features include:**
- Real‑time ML sound classification  
- Angle + distance estimation  
- Radar + heatmap visualization  
- Alert priority stack  
- Timeline drawer  
- High‑contrast accessibility mode  
- Multi‑room OSC sync  
- Full VR/XR holographic radar  
- Optional game‑object sound detection for VR engines  

**Platforms:**
- Desktop (Sci‑Fi Neon)  
- Tablet (Blueprint Greek)  
- Mobile (High‑Contrast)  
- VR/XR (Holographic 3D Radar)
